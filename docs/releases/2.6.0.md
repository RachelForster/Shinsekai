# Shinsekai 2.6.0

本次更新基于 **2.5.1**，新增桌面智能助手、角色资料检索，以及从静态立绘生成、动态制作到表情切换过渡的完整工作区，同时支持视频素材和聊天语音存档。

## 立绘智能生成

- 在人物页点击“立绘智能生成”，进入居中的独立工作区。静态立绘、动态立绘和过渡动画分为三个标签页，共用预览大小及透明背景检查设置；点击右上角 × 回到人物页，保留尚未保存的人物编辑。
- 可根据人物设定与补充要求规划多张提示词和标签，也可直接手写单张提示词。每张方案都能编辑、重绘和单独重试，勾选满意的结果后连同标签批量保存，或替换角色原有立绘。
- 自动提示词描述站姿、表情、双手姿势与必要道具；提供参考图时保持原图取景和人物比例，支持半身像。图片或现有动态立绘的首帧均可作为静态生成的参考。
- 点击结果或参考预览可打开图片／视频大图浮层；点击空白、右上角关闭或按 Esc 返回，保留原来的滚动位置与选择。

### 可选 MiniMax H3 工作流

- 附带 ComfyUI 画布版与 API 版工作流，可打开所在文件夹，访问模型下载页和安装教程。静态生成仍通过当前 T2I 服务，也可使用其他兼容图像工作流或 Stable Diffusion API。
- 使用 H3 生成静态立绘时，兼容工作流会缩短至最多 **39 帧**，自动从视频约 80% 的位置选取画面；可从保留的视频重新选帧，无需再次生成。带自定义引导帧或连接式时长的工作流保留原设置。
- 静态页新增“跟随工作流／高清／超清”分辨率选项，后两档分别约为 **70 万／100 万像素**，按参考图比例适配；更高分辨率需要更多显存和生成时间。
- 动态页支持多选角色已有立绘批量生成，也可取现有视频首帧重新制作。提供身体与头发微动、微风、眨眼等设置，保持镜头与原取景；闭眼、眯眼、单眼或特殊眼型会在提示词中要求保持原状。手写整段提示词按用户原文执行。
- 动态动作速度默认 **0.75 倍**，可调整并保存到输出视频。透明处理失败会保留原视频，支持单独重试。
- 可选择立绘生成 **22 帧单向过渡**，保存后在聊天切换对应立绘时播放。可分析角色最近聊天，按估计的常用程度推荐用户指定数量的过渡，减少批量生成数量。
- 过渡播放速度可在界面调整，预览和聊天共用并记住当前设备上的选择；已有素材无需重新生成。播放时平滑校正尺寸、位置和亮度，减轻切换闪烁及忽明忽暗。

### 透明处理与连接配置

- 提供 ToonOut 与 ISNet Anime 抠图选择，默认优先使用 ToonOut；未安装或初始化不可用时回退 ISNet Anime。自动选色色幕和 Alpha 边缘细化均可选，默认关闭，并可开启有色预览背景检查边缘。
- 动态立绘和过渡经过抠图与透明通道校验后保存为 **VP9 Alpha WebM**。普通 MP4 不会自动变成透明视频，H3 原视频也需经过透明处理。
- ComfyUI 设置增加“检测连接”，并区分标准服务、地址错误、不可达或需要鉴权等情况。秋叶／绘世整合包和 ComfyUI Desktop 可用自己的启动器启动，再关闭新世界自动启动并连接相同地址；连接成功后仍需确认工作流、节点与模型可用。

详细步骤见[立绘生成与 H3 指南](../CHARACTER_SPRITE_GENERATION_zh-CN.md)和[ComfyUI 连接指南](../COMFYUI_SETUP_zh-CN.md)。

## 桌面智能助手

- 设置页导航栏新增“助手”，支持多会话、流式 Markdown 回复、按会话保留草稿、停止任务及回答助手的提问。
- 复用当前 LLM 提供商、模型与凭据。首次准备会下载并校验 Pi 运行包，显示准备进度；无需另装 Node 或 Bun。
- 内置功能指引、故障排查、人物创建与插件开发技能，按任务需要加载。可通过已有应用接口管理人物与插件，并使用本机文件、搜索和命令工具；网页能力取决于实际安装并加载的浏览器插件。
- 展示当前活动与耗时，展开“执行过程”查看步骤状态及工具结果。交互助手不再受旧的固定任务时长和工具调用次数上限约束，可通过“停止”中断。
- 历史与执行过程可恢复；应用重启后排队任务需显式继续，退出应用会停止助手任务并收尾相关进程。旧会话保留原技能和模型快照，体验更新后的技能时请新建会话。

使用范围与配置见[助手接入说明](../AGENT_APP_INTEGRATION_zh-CN.md)及[Pi 运行说明](../AGENT_PI_zh-CN.md)。

## 角色资料与自动检索

- 背景页新增“资料管理”，可浏览、搜索、添加及删除资料条目，并指定哪些角色可以检索这些资料；角色重命名或删除后同步更新绑定。
- 支持从 TXT 文本预览并导入资料，显示导入进度与结果。资料与长期记忆使用独立存储，不会混入同一资料库。
- API 设置新增“资料检索”，可检查依赖、下载嵌入模型并设置每轮检索条数。启用后，聊天会按角色绑定检索相关内容，作为补充上下文；检索失败时继续原有聊天流程。
- **自动资料检索默认关闭**，与长期记忆共用嵌入模型。首次使用需安装所需依赖并准备模型，设置在下次启动聊天时生效。

## 视频素材、聊天语音与历史

- 角色立绘、主控头像和背景支持 **MP4**，可与图片混合导入并设置标签。列表显示视频封面，预览和聊天静音循环播放；主控头像保留裁剪设置。
- 聊天历史支持回放可用语音并单独保存，新增可选“开启语音存档”。未开启存档的语音仍可能随缓存失效，开启后也无法补回已经丢失的音频。
- 修复继续历史时的语音引用、旧缓存位置复用导致播放错音，以及语音存档未完整写入等问题。
- 聊天输入框支持上方向键找回最近提交的内容，方便修改后再次发送。
- 剧情支持删除已保存版本及关联聊天，并加强失败恢复、聊天启动就绪检查、会话关闭和资源释放。

视频格式与播放说明见[MP4 立绘与背景](../MP4_MEDIA_zh-CN.md)。

## 智能标注与升级提示

- 立绘智能标注使用当前 **Vision Adapter**，只补充空白标签；以 **2–3 个简短中文词语**描述情绪、表情和动作。视频取中间帧送入视觉服务，已有标签保留。
- Vision 默认“跟随 LLM”，沿用对应服务商的地址、密钥和未单独覆盖的模型。升级时会一次性清除旧自动模式中历史写入的 `deepseek-flash` 默认值；其他模型覆盖与手动适配器选择保留。如需固定该模型，可在升级后重新选择。远程视觉服务需支持图片输入。
- 升级前建议备份配置、角色资源、聊天记录和插件；已有图片立绘与动态模型可继续使用。回退时使用升级前的备份，避免旧版本读取新增字段或素材格式。
- 新世界不自动安装 ComfyUI、H3 节点或模型权重。先在自己的 ComfyUI 中跑通工作流，再连接新世界；服务地址、模型文件名和节点映射应与本机环境一致。
- ToonOut 需要单独准备兼容运行环境与模型；源码用户可参考 [requirements-toonout.txt](../../requirements-toonout.txt) 和 [setup_toonout.py](../../tools/setup_toonout.py)。ISNet Anime 首次使用也可能下载权重。抠图质量、H3 动作幅度及眼型保持仍需预览挑选，批量前建议先试单张。
- 透明视频需要支持 VP9 Alpha 的浏览器或 WebView，普通 MP4 的可播放性取决于编码与设备。Live2D 仍需自行准备已获授权的 Cubism SDK，发行包不含 SDK 或第三方角色模型。
