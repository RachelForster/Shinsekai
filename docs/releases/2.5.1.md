# Shinsekai 2.5.1

本次更新基于 **2.5.0**，重点是更自然的 MMD 日常表现、统一的形象取景、桌面与手机会话管理，以及回复演出的稳定性。

## 更自然的 MMD 表现

- 新增自动呼吸，胸部、躯干和头部产生轻微联动，改善角色静止时的表现，并让默认正面视角下的呼吸更容易观察。
- 新增间歇微风，让具备适配骨骼的头发和衣物随风轻动；微风有渐入、渐出和安静间隔，改善正面视角下的可见效果及动作切换后的衔接。
- 新增随聊天状态变化的视线：等待回复时轻微移开目光，回应时回到交流方向，空闲时偶尔短暂扫视。多个角色使用各自的节奏。
- 眨眼会与回复开始、语音结束和视线变化协调，加入偶尔的双眨眼和较慢睁眼，避免多个提示叠加成连续眨眼。
- 未选择显式姿势或动作时，具备完整适配手臂骨骼的模型使用更放松的默认手臂姿态；启用 PMX 模型自带的描边，保留模型原有的轮廓设置。
- 自动微动不会写入保存的预设；显式姿势和动作优先，编辑模式与系统“减少动态效果”偏好会停用相关自动演出。

## 统一的形象取景

- 聊天设置新增 **全身、半身、特写** 取景预设，并可调整显示高度比例及垂直位置，适用于静态立绘、MMD 和 Live2D。
- 同一角色切换立绘或模型状态时保留取景，避免表情变化后构图跳回默认值。
- 动态模型按实际显示尺寸渲染，改善半身和特写放大后的清晰度。

## 手机连接与会话管理

- **手机连接开关移至聊天工具栏**，不再放在 API 设置页。该选择保存在当前设备，默认关闭，并用于创建聊天、模板／剧情启动及继续上次聊天。
- 继续上次聊天时遵循当前设备的手机连接选择，不再被上次会话保存的旧选择覆盖。
- 聊天列表展示正在运行的会话，可重新打开本地聊天窗口、在已启用手机连接时显示二维码，或确认结束会话。
- 结束会话期间显示处理状态并防止重复操作；如果正在运行的会话已经变化，会提示刷新，避免误关新会话。
- 改善聊天列表观察运行状态时对语音播放的影响，避免仅查看列表就干扰正在播放的角色语音。

## 修复与可靠性

- 修复回复被打断后，后续内容已经生成并保存、却没有继续演出的问题；旧语音／媒体任务不再影响后续台词、错误提示和新打开的聊天会话。
- 修复部分导出器生成的有效 VMD 动作被误判为无效的问题，兼容未使用的导出器元数据，并继续校验完整插值控制矩阵、实际播放使用的控制值和文件完整性。

## 使用与升级提示

- 升级前建议备份用户配置、角色资源和聊天记录；已有静态立绘及 2.5.0 模型状态可以继续使用。
- 新增 MMD 自动演出依赖模型实际具备的骨骼和 morph；缺少对应绑定时会跳过相关效果。微风是程序性骨骼微动，当前 MMD 仍不支持物理模拟或自动跨模型骨骼重定向。
- Live2D 仍为可选试验功能，官方发行包不附带 Cubism SDK 或第三方模型。使用方式见 [Live2D 集成说明](../LIVE2D_INTEGRATION_zh-CN.md)。
