# Shinsekai 2.5.0

本次更新基于 **2.4.1**，重点是动态角色形象、MMD 姿势与动作预设，以及更完整的主控人物体验。

## MMD 模型与动作

- 新增 **MMD / PMX 模型**导入、角色预览和聊天舞台显示，无需 Live2D SDK。导入时一并收集模型需要的贴图。
- 可以手动调整表情权重、指定口型和眨眼绑定。播放角色语音时，模型会根据音量开合嘴部，并自动眨眼；模型需要具备相应的 morph。
- 镜头默认接近眼睛高度，支持调整朝向、俯仰、缩放和水平／垂直取景。镜头设置随预设保存，改善正面光照，并可单独重置镜头。
- 支持混合多选 **VPD 姿势与 VMD 动作**，一次最多导入 100 个。每个文件生成独立预设，默认以文件名作为标签，可在查看面板播放，供聊天按编号或标签选用。
- 姿势保持不变；动作播放一次后保持结束姿势。预设之间平滑衔接，同一模型不再因切换状态消失后重新出现。恢复历史时保留结束姿势，不重新播放动作。

## 更自然的动态表现

- MMD 和 Live2D 在角色说话时加入轻微头部运动，语音结束后平滑归位；不会写入保存的预设，也不会抢占显式头部动作。
- Live2D 表情和参数切换加入平滑过渡，快速连续切换也能从当前姿态接续。
- 动态形象的查看区沿用立绘列表；点击“新建状态”或“编辑状态”才打开编辑器，桌面上左侧调整参数、右侧预览模型，保存后生效，取消不保存草稿。
- 编辑模式暂停自动嘴型、眨眼和头部微动；遵循系统的“减少动态效果”偏好。

## 主控人物与聊天体验

- 主控人物设置按钮旁显示当前人物，弹窗增加确认按钮；选择主控人物后，仍可设置其他人物的主次角色。
- 主控头像放在对话框内左侧并垂直居中，姓名名牌保持原来的位置。
- 新增 **“AI 可以编写主控回答”** 开关，**默认开启**。希望完全由自己决定主控台词时，请在主控人物弹窗关闭它；“朗读主控台词”仅控制已有台词是否朗读。
- 主控人物选项随聊天模板保存，改进人物头像裁剪草稿与 Raging Loop 主题布局。

## 修复与可靠性

- 修复 Windows 前端地址和聊天窗口重载的 loopback 判定，避免相关白屏、启动等待及媒体加载失败。
- 修复动态模型在流式聊天中的资源地址、聊天舞台显示和 MMD 窗口拖动问题。
- 修复恢复历史时初始立绘可能覆盖最后一次角色立绘的问题。
- 编辑角色、导出和重新导入 `.char` 时保留动态模型资源银行；静态“删除全部立绘”不再删除动态模型文件。
- 加强 PMX 完整性、贴图与动作引用校验；配置写入失败时报告错误并回滚本次新增资源，避免把失败的保存当作成功。

## 使用前请注意

- **Live2D 仍为可选试验功能。官方发行包不附带 Cubism Core / Framework 或样例模型**；直接安装发行包不能开箱即用 Live2D。使用前需要按项目的 Live2D 集成文档，准备已获授权的 Cubism SDK for Web **5-r.4** 并自行构建。静态立绘和 MMD 不受影响。
- MMD 当前**不支持物理模拟、VRM 或 Blender 源工程直接导入**；VMD 的镜头轨道不会覆盖用户镜头。跨模型动作未做自动骨骼重定向，可能需要手动调整。
- 模型、贴图和动作请自行提供并遵守各自授权，本次发行不包含测试使用的第三方模型。
- 替换模型会清空该格式的活动状态和标签，以免继续使用不兼容的旧状态；请先备份角色包，在新模型上重新创建预设。
- 升级前建议备份用户配置和资源目录。已有静态立绘可以继续使用；新增的模型和动作配置不保证旧版本能够读取，回退时请使用升级前的备份。
