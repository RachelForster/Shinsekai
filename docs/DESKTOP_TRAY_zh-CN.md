# 托盘与主窗口关闭

点击主窗口关闭按钮或使用 Alt+F4，默认显示与主程序配色一致的确认弹窗：

- **退出程序**：结束程序，聊天和日程提醒停止。
- **最小化到托盘**：隐藏主窗口，程序继续运行，日程提醒照常投递。
- **取消**：保留窗口；按 Esc 或关闭弹窗也表示取消。

勾选“记住我的选择”后，退出或驻留托盘的选择会保存到桌面配置目录的
`background.json`，下次关闭主窗口直接执行。取消不会记住任何选择；保存失败时保留弹窗，
可以重试或取消。旧版配置没有记忆标记，升级后首次关闭也会询问。

在“系统设置 → 托盘与睡觉提醒 → 关闭主窗口时”可随时选择“每次询问”、
“最小化到托盘”或“退出程序”，点击保存生效。“最小化主窗口到托盘”仍单独控制最小化按钮。

系统托盘不可用时禁用驻留选项；之前记住的驻留选择会回到询问，避免隐藏后无法恢复。
托盘菜单中的“退出 Shinsekai”是明确退出操作，直接结束程序。聊天窗口仍沿用原来的关闭行为。

关闭请求、可用性检查和配置持久化由 Rust 桌面壳负责。前端确认弹窗不依赖 Python 后端启动，
并会在挂载时读取尚未处理的关闭请求，以覆盖主窗口刚启动时的关闭操作。

## 角色台词和语音

睡觉提醒和角色工具创建的日程到点后，先显示原有文字，随后使用当前配置的 LLM，
根据该角色的性格、简介和本次日程生成简短台词。提示词由 `ai/llm/template/reminder.py`
中的 Section 拼接。界面文字使用界面语言，朗读台词使用系统语音语言，保持相同意思。

语音通过当前 TTS 服务合成，沿用角色的模型、参考音频、语速和音量配置；无需打开聊天。
服务未配置、超时或生成失败时保留文字提醒。冷启动服务可能需要等待，文字投递不受影响。
退出整个程序后不再投递提醒，驻留托盘时仍可生成和播放。

小卡片只增加静音和重播按钮。每次到点的语音自动播放一次，多条语音依次播放。
关闭卡片或按 Esc 会停止播放；语音生成完成也不会重新打开已隐藏的卡片。
静音选择会保存，取消静音不会补播错过的提醒，可以手动重播。

语音文件使用独立文件名保存在 `cache/reminder_audio`，成功合成时清理七天前的缓存。
聊天与提醒共用 TTS 服务时，通过跨进程锁串行切换角色模型和合成，避免串音色。
