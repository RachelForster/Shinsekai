# MP4 立绘与背景

在角色的「图片／视频立绘」或背景素材列表中，可以使用同一个上传入口混合选择 PNG、JPEG、WebP、GIF 和 MP4 文件。

- 每个 MP4 和图片一样占用一个素材条目，可以编辑情绪／场景标签，并按标签在聊天中切换。
- 素材列表显示暂停的视频封面；选中后的预览和聊天中的视频默认静音循环播放。视频的音轨不会替代角色语音或背景音乐。
- 视频立绘沿用缩放、拖动和全身／半身／特写取景；视频背景铺满舞台。
- 主控头像使用普通立绘列表中的素材；MP4 静音循环播放，GIF 保留动画，二者均支持头像裁剪预览和聊天中的裁剪参数。聊天启动仍默认使用第 0 个立绘。
- 隐藏舞台或将页面切到后台时暂停视频，恢复可见时继续播放；切换素材或关闭页面后释放旧视频。
- MP4 是容器格式，能否播放取决于文件编码和设备。建议使用 H.264 编码的 MP4；无法播放时，编辑预览显示提示，聊天继续运行。
- 视频不会自动去掉原有底色。需要透明背景的角色素材可继续使用透明图片或 GIF。
- 智能标注支持 MP4：自动读取视频中间帧，再调用当前配置的 Vision Adapter。角色立绘标签为 2–3 个中文情绪、动作词；已有标签会保留。

已有角色和背景配置无需迁移；图片和 GIF 的导入与选择方式保持一致。

## 待机与说话立绘

在「立绘智能生成 → 动态立绘」中，可选择「待机版」或「说话版」。新生成的待机版使用 73 帧，默认 0.75 倍速约 4.1 秒，保持原嘴形；说话版使用 H3 原生的 56 帧，原速 24 FPS 下约 2.3 秒，生成两组短句中的连续音节嘴形变化。身体微动开启时，头部、躯干、手臂和发梢会轻微配合句子重音，同时保持肩颈比例和原手势。两者共用参考图、固定镜头、动作设置、逐帧抠图和透明 WebM 校验，已有视频保持不变。

说话版仅使用首尾图约束闭合循环，不再自动插入中途的静止原图约束，以免把嘴形和动作反复拉回静止。自定义提示词和工作流内已有的手动引导仍会保留。此前生成的说话视频需要重新生成，才能使用新的说话动作。

说话版可多选角色中已保存的图片或动态立绘，以首帧为参考批量生成。预览后点击「保存为说话立绘」，结果绑定到对应来源，保留原立绘、标签和语音设置；再次生成并保存会更新说话版。来源卡片显示是否已有绑定，角色包导入导出也包含说话视频。

聊天播放对应角色的语音时切到说话版，沿用立绘的取景和高亮，并校正人物的大小、位置和亮度。根据即时音量识别停顿，忽略音节间的极短空隙；停顿时暂停在当前帧，再有声音时继续。播放速度在原速的 0.92–1.08 倍之间平滑跟随声音强弱，模型形象原有的口型平滑不受影响。语音结束、中断或播放失败后恢复待机版。舞台隐藏和后台页面暂停视频，切换表情仍优先播放原有过渡。未绑定或无法播放说话版时沿用原立绘。这里是随声音启停的循环视频，并非逐字、逐音素的口型同步。

## 过渡动画的尺寸与亮度

更新立绘时优先播放已保存的对应单向过渡；没有对应过渡时，图片和视频立绘统一使用“淡出 → 淡入”，两段各约 160 毫秒。会先等目标图片或视频首帧解码完成，再淡出旧立绘，在完全透明时切换并淡入新立绘。视频沿用静音循环播放；初次显示、恢复历史、舞台隐藏及系统“减少动态效果”模式不播放切换动画。

过渡生成页的「过渡播放速度」可选 0.5×、0.75×、1×、1.25×、1.5×、2×，并显示对应的预计时长。预览与聊天切换共用这个倍速，自动记住当前设备上的选择；调整已有过渡无需重新生成。

聊天播放过渡时，会根据原立绘、过渡首尾帧和目标立绘的透明前景，自动平滑校正过渡的大小、位置和亮度，减轻不同画布比例、透明留白和生成色差造成的交接跳变。说话高亮和非说话角色的变暗仍由同一舞台容器统一应用。

已有透明过渡同样生效，无需重新运行 H3、重新抠图或修改原文件。校正参数按素材文件缓存；素材变化时自动重新读取。无法读取透明前景的旧素材沿用原播放方式。
