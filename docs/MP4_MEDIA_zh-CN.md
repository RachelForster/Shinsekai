# MP4 立绘与背景

在角色的「图片／视频立绘」或背景素材列表中，可以使用同一个上传入口混合选择 PNG、JPEG、WebP、GIF 和 MP4 文件。

- 每个 MP4 和图片一样占用一个素材条目，可以编辑情绪／场景标签，并按标签在聊天中切换。
- 素材列表显示暂停的视频封面；选中后的预览和聊天中的视频默认静音循环播放。视频的音轨不会替代角色语音或背景音乐。
- 视频立绘沿用缩放、拖动和全身／半身／特写取景；视频背景铺满舞台。
- 主控头像使用普通立绘列表中的素材；MP4 静音循环播放，GIF 保留动画，二者均支持头像裁剪预览和聊天中的裁剪参数。聊天启动仍默认使用第 0 个立绘。
- 隐藏舞台或将页面切到后台时暂停视频，恢复可见时继续播放；切换素材或关闭页面后释放旧视频。
- MP4 是容器格式，能否播放取决于文件编码和设备。建议使用 H.264 编码的 MP4；无法播放时，编辑预览显示提示，聊天继续运行。
- 视频不会自动去掉原有底色。需要透明背景的角色素材可继续使用透明图片或 GIF。
- 智能标注支持 MP4：自动读取视频中间帧，再调用当前配置的 Vision Adapter。角色立绘标签为 2–3 个中文情绪、动作词；已有标签会保留。

已有角色和背景配置无需迁移；图片和 GIF 的导入与选择方式保持一致。

## 过渡动画的尺寸与亮度

聊天播放过渡时，会根据原立绘、过渡首尾帧和目标立绘的透明前景，自动平滑校正过渡的大小、位置和亮度，减轻不同画布比例、透明留白和生成色差造成的交接跳变。说话高亮和非说话角色的变暗仍由同一舞台容器统一应用。

已有透明过渡同样生效，无需重新运行 H3、重新抠图或修改原文件。校正参数按素材文件缓存；素材变化时自动重新读取。无法读取透明前景的旧素材沿用原播放方式。
