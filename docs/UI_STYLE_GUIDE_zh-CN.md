# 界面样式规范（按钮与导航）

以 `glass-button-preview.html` 为当前视觉参考，保持现有页面布局。主题色使用 `--theme-accent`，界面背景为随主题色变化的浅色；不使用明显渐变或浓重色块。

文字按钮使用胶囊形，图标按钮使用圆形；表面为浅主题色、细边框和柔和阴影。悬停轻微提亮，按住时轻微下沉并缩小，松开后恢复。危险操作保留独立的警示色，禁用和键盘焦点必须可辨认，减少动态效果设置下取消动画。

侧边栏保持原有排版，选中项使用均匀的淡主题色背景、细边框和清晰文字；未选中项悬停效果更轻，不出现明显白块。

主题色变化时保持文字和控件可读。深色模式、极浅或极深主题色、危险和禁用状态，以及各内页自定义控件仍需逐页视觉验证；不应将测试页配色直接强制覆盖所有控件。
