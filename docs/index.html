Zero-Setup All-in-One Portable

All-in-One Portable Bundles

Extract, enter your LLM API key, and launch — ships with embedded Python, Qwen3-TTS 0.6B GGUF voice cloning (auto voice language), Sherpa-ONNX streaming ASR, Qwen3-VL-2B GGUF + RapidOCR screen perception, ONNX memory, and the official Pi Agent.

Hugging Face (Global) ModelScope (China Mirror)

Supported targets: windows-x64 · windows-arm64 · macos-arm64 · linux-x64 · linux-arm64

Extract to an ASCII/English path; user configs, saves, and models stay self-contained in data/ (.shinsekai-portable). On macOS, run xattr -cr Shinsekai.app if Gatekeeper prompts. Windows ARM64 omits Sherpa-ONNX and RapidOCR due to upstream wheel availability.

快速开始

  1. 下载对应系统版本（推荐直接下载 Portable 绿色整合包，或使用上方 Release 按钮 / 网盘镜像）：

    百度网盘 夸克网盘 Google Drive

  2. 解压或安装并运行：Portable 版请在纯英文路径启动 shinsekai.exe（Windows）、Shinsekai.app（macOS）或 ./shinsekai（Linux）；标准安装包对应 .msi / .exe、.dmg、.AppImage / .deb
  3. 启动 Shinsekai 后，在 API 设定 填写 LLM 供应商、模型 ID、API Key 与 Base URL，保存
  4. Portable 整合包已预置并默认开启本地 Qwen3-TTS 0.6B GGUF 语音克隆（auto 自动识别语种）；也可在 API 设定 → 语音模块 下载 Genie TTS / GPT-SoVITS
  5. 在 角色管理 导入角色包（更多见 社区资源），打开 聊天模板 生成模板并 启动聊天

🔄 更新软件：设置页面 → 插件 → 发现插件 → 更新软件，即可升级到最新版

开发者安装（源码）

  1. 下载 GitHub 源码包（zip / tar.gz）并解压，或 git clone https://github.com/RachelForster/Shinsekai
  2. 创建项目标准环境（推荐使用 environment.yml）： 
    conda env create -f environment.yml
conda activate shinsekai
  3. 构建 React 前端： 
    cd frontend
pnpm install
pnpm build
cd ..
  4. 使用平台脚本启动：Windows 运行 scripts\start.bat（或 scripts\start-tauri.bat），macOS 运行 scripts/start.command，Linux 运行 ./scripts/start.sh；Qt 设置页和聊天窗已退出
  5. React 设置中心用于管理 API、角色、背景、聊天模板、小工具、插件和 MCP
  6. 完成配置后按上面的「第一次对话」流程启动聊天

核心能力

  • 多 LLM 与三语界面 — DeepSeek / OpenAI / Claude / Gemini，全栈 简中 / EN / 日本語
  • 本地语音克隆与 TTS — 内置 Qwen3-TTS 0.6B GGUF（auto 自动语种），支持 GPT-SoVITS / Genie TTS / CosyVoice 与口型同步
  • ASR 语音识别 — 默认 Sherpa-ONNX 双阶段流式识别（Zipformer + SenseVoiceSmall），兼容 Vosk / Whisper
  • 多形态形象与舞台 — 静态 / MP4·WebM 透明立绘、MMD、Live2D、服装分组、全屏自适应 VN 对话与可插拔 XML 演出
  • 屏幕感知与长期记忆 — Qwen3-VL-2B GGUF + RapidOCR 7 场景感知，SQLite + FTS5 + ONNX 混合记忆与 RAG 资料库
  • 剧情画布、回放与导出 — AI 分支节点画布、原舞台回放、PNG 长图、MP4/WebM 录制与离线可游玩 VN 包导出
  • 桌面助手与扩展生态 — Pi Agent 运行时、托盘日程语音提醒、ComfyUI / MiniMax H3、5 套皮肤、插件 SDK 与 MCP
