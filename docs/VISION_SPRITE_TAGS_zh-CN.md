# 立绘智能标注与视觉服务默认配置

“智能标注”只补充空白立绘标签，使用任务开始时当前配置的 Vision Adapter。标签为 2–3 个简短中文情绪、表情和动作词，例如“开心，微笑，挥手”或“害羞，低头”。输出不合格式时重试一次，仍不合格则报告失败并保留空白，已有标签保持原样。

MP4 / WebM 立绘会先取视频中间帧，再将这一张图片交给视觉服务；临时帧使用后删除。此能力通过运行依赖 `av`（PyAV）读取本地视频，避免加载整段视频到内存。源码安装的 `requirements.txt`、开发测试依赖与桌面运行时依赖均包含 PyAV。

视觉适配器的默认选项为“跟随 LLM”。内置服务商会使用当前 LLM 对应的视觉适配器，共用该服务商的 URL 和密钥；没有单独指定视觉模型时也沿用该服务商的 LLM 模型。视觉模型和适配器的显式配置优先。当前 LLM 没有对应内置视觉适配器时，沿用可用视觉插件的回退链。

例如 `vision_provider: auto` 配合空的 `vision_model: {}` 会跟随当前 LLM；如果手动选择 `gemini` 并指定 `vision_model.gemini`，切换 LLM 不会覆盖它。

旧配置未包含 `vision_config_version` 时，会执行一次迁移：自动模式中历史保存的 `vision_model.deepseek: deepseek-flash` 被清除，恢复跟随 LLM；其他模型覆盖和手动指定的视觉适配器保留。保存后记录迁移版本，之后再次明确选择 `deepseek-flash` 会作为用户覆盖保留。旧自动配置无法区分该值当时是默认写入还是手动选择，需要固定此模型时可在升级后重新选择。

设置页会显示实际跟随的服务商和模型。直接编辑配置文件后重新启动应用；通过设置页保存则使用更新后的配置。使用远程视觉服务时，图片会发送到所选服务商。
