# 立绘智能生成与 MiniMax H3 接入指南

第一次使用本地 H3，建议按 **ComfyUI 单独生成成功 → 新世界连接同一服务 → 先试一张立绘 → 批量生成** 的顺序操作。这样能先确认模型与节点可用，再检查应用连接。已经跑通同一套模型和工作流的用户可以直接从第二步开始，无需每次手动生成视频。

立绘生成通过当前配置的 T2I 服务工作，也支持其他 ComfyUI 图像工作流和 Stable Diffusion API。H3 是可选方案。尚未配置图像服务时，可以先用已配置的 LLM 生成提示词与标签；生成图片仍需要图像服务。新世界不会自动安装 ComfyUI 或下载 H3 权重。

**秋叶／绘世整合包、ComfyUI Desktop 或其他已有环境**，先用自己的启动器启动，关闭新世界的自动启动，再填入相同的服务地址即可。不要求使用官方便携版。首次配置建议先阅读[ComfyUI 连接指南](COMFYUI_SETUP_zh-CN.md)，其中说明了启动方式、两种 JSON 格式和常见错误。

## 在生成窗口中操作

1. 在左侧选择参考图（可选），填写表情、动作和双手姿势等要求，设置方案数量与自动抠图。点击设置栏底部的“生成提示词与标签”；规划只使用人物设定生成方案，此时不会生成图片。
2. 在右侧查看每个方案的中文标签，需要调整时展开“查看 / 编辑提示词”，然后点击右上方“生成待处理立绘”。生成进度和错误保持可见，单张失败可单独重试。
3. 对比图片，按需重绘、抠图或从原始视频选帧，勾选满意的结果。底部始终显示选中数量，点击“添加到立绘集”将图片和标签一起保存到当前角色。

“模型与工作流”入口位于预览区右上方，首次打开窗口时展示资源指引；生成方案后自动收起，可随时重新展开。桌面窗口采用左右分栏，窄屏按设置、预览的顺序纵向排列。

## 手写单张提示词与逐张重绘

静态和动态页的预览区上方都有“手写单张”。点击后直接出现一张展开提示词编辑区的草稿，填写提示词、调整标签，再点该卡片的“生成立绘”；不需要先填写人物性格或调用 LLM 生成方案。静态页可沿用左侧参考图，也可不选参考图。动态页需要先在立绘库中仅选一张静态来源，或上传单张参考图，才能创建手写草稿。

已有的静态或动态结果均可展开“查看 / 编辑提示词”，修改这一张的完整提示词后点击“重绘”。动态提示词一经手动编辑，会替代该张的身体微动、眨眼等动作预设，不再自动拼接预设姿态或镜头描述；需要固定镜头、保持取景或限制颈肩动作时，应在自己的提示词中写明。此张的参考图、首尾同图、动作速度、稳姿参考帧和透明处理仍会保留。其他卡片不受影响。

修改提示词后，旧结果保留供对比，但暂时不能选中保存；重绘成功后才恢复保存。重绘失败可继续修改、重试，或通过“继续生成待处理动态立绘”处理已修改的动态卡片。原视频已生成但抠图失败时，仍应使用“重试透明处理”，无需再次生成视频。手写卡片和智能方案共用每次最多 12 个方案的额度，标签可自行调整。

## 替换角色现有立绘

单张静态或动态结果通过校验后，可点卡片上的“替换原立绘”。确认窗口优先定位到这张结果参考的现有立绘；没有对应来源时，需手动选择目标，并可对比原立绘与生成结果。确认后，新媒体和当前标签写回该项，不追加列表项，保留原位置、语音配置及原始文件；编辑器里未保存的人物设定与语音编辑也会保留。若目标在生成期间被移动、改换或尚未保存，会提示刷新后重新选择，避免误替换。提示词已修改但未重绘、动态结果未完成透明处理时，不能替换。

## 生成透明动态立绘

生成窗口顶部可切换“静态立绘 / 动态立绘”。动态页切到“立绘库（多选）”后，右侧大图选择区列出当前角色已有静态立绘和本窗口新生成的静态结果，可逐张勾选、全选或清空；MP4、WebM 等视频不作为来源。也可切换“上传单张”，或在静态结果卡片点击“制作动态立绘”，自动选中对应来源。

所选立绘共用身体微动、眨眼、微风等动作设置，但每张保留自己的原标签；默认标签仅用于尚未标注的来源。动作设置与批量按钮保留在左侧，开始生成后自动收起来源选择区，可通过“选择来源”重新展开。批量任务按顺序逐张生成并完成透明处理，界面显示队列进度和单张进度。单张失败不会中断后续任务。点击“本张完成后停止”后，未开始的项目会保留在右侧，点击“继续生成待处理动态立绘”可沿用该批开始时的设置继续，不重复创建方案；已生成原视频但抠图失败的项目应单独“重试透明处理”，不必重跑 H3。

每次最多保留 12 个静态或动态方案。来源较多时，“选择前 N 张”按剩余额度选择；可先保存、移除已有结果，再继续下一批。

默认开启身体微动和自然眨眼。身体各部位和放松的四肢以极小幅度缓慢、协调地晃动，双脚和身体重心保持原位，保留原手势；头发轻微晃动，带少许自然滞后。微风开关额外增加头发和衣摆的轻柔摆动。眨眼提示以整段一次舒缓的眼睑闭合、其余时间自然睁眼为目标。固定原图取景、视点、焦距与原表情，不补写人物外貌；模型对动作次数和幅度的控制仍需预览确认。

“动作速度”默认 **0.75 倍**，也可选 0.5 倍或原速。该设置保留全部生成帧并降低透明视频的时间轴帧率，身体、眨眼和头发微动会一起放慢，保存到角色后的播放与导出的 WebM 都使用这一速度。默认 107 帧、24 FPS 的原视频在 0.75 倍下约为 5.94 秒；放慢后的输出最长 12 秒，超出时需缩短工作流时长或提高动作速度。批量任务保存开始时的速度设置，重试抠图也保留同一速度。

肩部幅度单独约束：肩线几乎不动，保持参考图中放松的肩高和肩线角度，只允许近乎不可察觉的跟随；保持原颈长、可见颈部轮廓、耳朵到肩膀及下巴到衣领的间距。头、颈和身体保持原有对齐，手臂与头发仍可轻微晃动。眨眼限定为眼睑动作，并保持原来的头部倾角。这些是正向姿态描述，H3 不会精确执行像素或百分比限位，仍应预览挑选；降低“动作速度”只改变节奏，不会减小已经生成的肩部位移。

“首尾使用同一参考图”会同时为 H3 首帧、尾帧设置同一张静态立绘，帮助循环衔接；生成模型仍可能产生动作或构图偏差，应预览确认后保存。旧视频的动作不会随预设更新而改变，需要点击该张“重绘”重新生成；“重试透明处理”只处理背景，不会改变动作。

动态任务在接近首尾的约 10% 和 90% 位置，通过原生 `MiniMaxH3AddGuide` 节点加入同一参考立绘，辅助保持站姿和循环衔接，中段留给连续的缓慢动作。这些节点只加入当前提交的任务副本，不修改磁盘上的 API 工作流；不需要额外模型。请在 H3 节点中用整数设置 `length`，应用会按照 H3 的 `17k + 5` 帧数规则计算锚点位置，极短视频会去除重复或首尾位置。

动态页要求当前 T2I 服务为 ComfyUI，并选择包含 `MiniMaxH3ImageToVideo` 的 API 工作流。模型和节点沿用本指南；原视频的时长、帧率、分辨率沿用工作流，透明输出另应用所选动作速度。透明处理支持 1–60 FPS、最多 200 万像素的原视频，原视频与调速后的输出均须在 12 秒内；配套默认原视频为 107 帧、24 FPS，约 4.46 秒。

透明处理为必选：H3 生成原视频后，复用本地 `isnet-anime` CPU 会话逐帧抠图，再通过 PyAV 的 `libvpx-vp9` 编码为带 Alpha 的透明 WebM，不会将普通 H.264 MP4 直接标记为透明。编码后使用支持 Alpha 的解码器逐帧校验，保存前再检查文件；全不透明、人物被全部抠除或缺少 Alpha 的结果会被拒绝。抠图边缘仍需通过棋盘格预览检查。

抠图失败会保留原视频并禁用保存，可点击“重试透明处理”，无需再次运行 H3。通过校验的 WebM 与当前标签一起添加到现有立绘集，在聊天中静音循环播放。需使用支持 VP9 Alpha 的浏览器或 WebView；无法播放时应升级运行环境，不能用普通 MP4 替代透明结果。

首次抠图可能需要下载 `isnet-anime` 权重；缺少 `av`、`rembg[cpu]`、ONNX Runtime 或 VP9 编码器时会显示处理错误，安装本项目运行依赖后重试。抠图在 CPU 上进行，避免继续占用 H3 显存。

立绘生成窗口提供 **“打开工作流文件夹”**，会通过系统文件管理器打开当前新世界实际运行目录中的工作流文件夹，并显示完整路径。旁边的 **“H3 模型下载页”** 和 **“H3 安装教程”** 可直接打开官方资源；展开首次使用说明后，还能点击每个模型文件进入对应下载页并查看放置目录。

| [minimax_h3_t2v.json](../ai/t2i/workflows/minimax_h3_t2v.json) | **导入 ComfyUI**，试跑不带参考图的文生视频。 |

## 1. 先在 ComfyUI 单独生成视频

### 准备节点与模型

按 [ComfyUI 官方 H3 原生工作流教程](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-native) 安装支持 H3 原生节点的 ComfyUI，获取官方可视化模板。模型来源与版本要求以官方教程及 [Comfy-Org/MiniMax-H3 模型仓库](https://huggingface.co/Comfy-Org/MiniMax-H3) 为准。

本项目附带的 API 工作流使用以下文件；目录相对于 ComfyUI：

| 模型文件（点击进入下载页） | 放置目录 |
| --- | --- |
| [minimax_h3_fl2va_pruned_int8_convrot.safetensors](https://huggingface.co/Comfy-Org/MiniMax-H3/blob/main/diffusion_models/minimax_h3_fl2va_pruned_int8_convrot.safetensors) | `models/diffusion_models/` |
| [qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors](https://huggingface.co/Comfy-Org/MiniMax-H3/blob/main/text_encoders/qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors) | `models/text_encoders/` |
| [minimax_h3_video_vae_int8_convrot.safetensors](https://huggingface.co/Comfy-Org/MiniMax-H3/blob/main/vae/minimax_h3_video_vae_int8_convrot.safetensors) | `models/vae/` |
| [minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors](https://huggingface.co/Comfy-Org/MiniMax-H3/blob/main/loras/minimax_h3_fl2v_turbo_8step_v1.0_comfyui_bf16.safetensors) | `models/loras/` |

配套无声工作流只需要这四个模型文件，无需下载整个模型仓库。

文件名必须与 API 工作流对应。若使用不同量化版本，请同步修改工作流的模型名称，并先独立验证该组合。官方可视化模板如果保留音频分支，还需按官方教程安装音频 VAE；项目附带的立绘 API 工作流输出无声视频，不使用音频分支。

### 完成一次独立测试

1. 启动 ComfyUI，打开它实际监听的地址。默认常见地址为 `http://127.0.0.1:8188`；本项目 H3 配置示例使用 `8189`，请按自己的服务填写。
2. 将上表中的 `minimax_h3_i2v.json` 拖入 ComfyUI 画布。上传一张完整、人物居中的参考立绘，检查已安装的模型。附带工作流已经配置 8 步 Turbo；也可以使用官方教程的可视化模板或模板库中的 **MiniMax H3 I2V**，按模板启用 Turbo。
3. 先用较低分辨率生成一段短视频。本项目测试参数为 **480×832、107 帧、24 fps、8 步**；调整时保持与所用 H3 模板兼容的尺寸和帧数。手动测试也要让画布比例接近参考图，避免默认画布将人物拉伸。半身参考图保持半身取景；可在动作提示词后加上 `preserve the reference image's exact framing and crop, locked-off static camera, fixed viewpoint and focal length throughout`，不要同时要求 `full body, full scene`。
4. 确认任务成功，并能在 ComfyUI 查看输出视频。需要无参考图生成时，再导入 `minimax_h3_t2v.json` 验证。先解决缺失节点、模型加载、显存不足等报错，然后再连接新世界。

**可视化工作流与 API 工作流不同。** 不带 `_api` 的文件用于导入 ComfyUI；带 `_api` 的文件用于新世界提交任务。配套文件使用相同的节点 ID、模型与生成参数。不要把 API 文件无法正常展示为画布当成模型故障。第二步在新世界选择对应的 API 文件。自行修改模型或画布参数后，需同步修改 API 文件，或从 ComfyUI 重新导出 API 工作流，并确认实际节点 ID。

## 2. 在新世界连接同一个服务

保持已经跑通的 ComfyUI 运行，使用项目附带的 API 工作流时按下表设置。官方模板跑通说明模型环境可用；第三步的首张立绘测试用于确认 API 工作流和新世界之间的配置也正确。

API 设定 → 图像生成服务，先选择“本机 ComfyUI”或“自定义”，再填写下表参数，适配器选 `comfyui`。不要把模型名填成适配器名。“补全缺失的默认值”保留已有本机端口和节点 ID，但通用默认节点值不能代替 H3 映射。下面的节点 ID 仅适用于项目附带的两份 API 工作流：

| 设置 | 值 |
| --- | --- |
| API 地址 | H3 ComfyUI 地址，例如 `http://127.0.0.1:8189` |
| 自动启动 | 秋叶／绘世、Desktop、已自行启动的服务均关闭；官方 Windows 便携版可选 |
| 官方便携版根目录 | 仅开启自动启动时填写，需包含 `python_embeded/` 和 `ComfyUI/`；其他情况无需填写 |
| 默认工作流 | 项目内 `ai/t2i/workflows/minimax_h3_i2v_api.json` 的绝对路径 |
| 提示词节点 ID | `131` |
| 输出节点 ID | `92` |

在 ComfyUI 扩展配置中填写：

| 设置 | 值 |
| --- | --- |
| `reference_node_id` | `114` |
| `text_only_workflow_path` | `ai/t2i/workflows/minimax_h3_t2v_api.json` 的绝对路径 |
| `generation_timeout` | `2400`，首次加载或内存换页时可适当增加 |
| `startup_args` | 仅用于自动启动官方便携版：`--windows-standalone-build --reserve-vram 1.5 --disable-all-custom-nodes --disable-partner-nodes` |

启动端口自动从 API 地址读取。直接修改 `data/config/api.yaml` 后需要重新启动应用，让配置重新加载。

工作流路径必须是当前电脑上真实存在的 API JSON 文件路径，不能照抄他人的 `C:/AI/...`。连接已经运行的本地或远程 ComfyUI 时关闭自动启动；只有希望由新世界启动官方 Windows portable 版时才开启并填写根目录。秋叶整合包使用自己的启动器，API 格式相同仍需保证已安装 H3 所需的内核节点和模型。上面的启动参数适用于本指南的 H3 原生节点配置，自定义工作流需要的节点不应被禁用。

这里的 API 地址必须与第一步访问的地址一致。本地 H3 不需要 MiniMax 云端 API Key。LLM 用于设计提示词和标签，需要单独在新世界中配置；已有立绘的智能标注还需要可用的 Vision 服务。

地址旁的“检测连接”可在保存前检查当前地址，只读取 ComfyUI 系统状态，不启动服务、不提交生成任务。检测成功仍需按工作流安装 H3 节点与模型，再试生成一张立绘；修改地址后应重新检测。

## 3. 生成并保存立绘

保存角色并填写人物性格与设定后，在角色编辑页点击“立绘智能生成”。先选择一张现有立绘作为参考，将数量设为 1，生成提示词和标签，再点击“生成待处理立绘”。确认人物比例、表情和双手姿势符合预期后，再增加数量批量生成。有参考图时运行 H3 图生视频工作流；配置了 `text_only_workflow_path` 时，无参考图会自动使用文生视频工作流。当前自动提示词只描述动作、表情与道具，建议提供参考图传递人物外貌；没有参考图时无法保证与现有角色外观一致。T2I Manager 保持返回静态图片，ComfyUI 适配器会下载视频并自动提取中间帧。

自动设计的提示词只包含动作、表情与必要道具，不描述人物外貌、服装或画风。每张立绘保持站立姿态，主要变化表情、手部与上半身动作，避免坐、跪、蹲、躺、跳跃或行走等姿态。每条提示词都明确描述眉眼／视线和嘴形的变化，并交代双手姿势与位置。动作在原画幅内完成；手脚被参考图裁切时，不要求为显示它们扩大取景。需要道具时只补充握持或展示动作所需的描述。

### 固定镜头，保留参考图取景

有参考图时，自动提示词保持原图的构图、裁切、机位、人物占比和画面位置：半身像保持半身，局部像保留原裁切。站立姿态不要求双脚可见，也不要求双手都入镜。程序不会追加 `full body, full scene`。无参考图时保留全身立绘要求；两种模式都会追加固定镜头、固定视点与焦距。

例如，有参考图时可以使用：

```text
make the character stand and smile warmly with relaxed eyebrows and gently curved lips, raise the open right hand beside the face and keep the left hand relaxed at the side, preserve the reference image's exact framing, crop, camera angle, character scale and screen position throughout, keep all pose changes within the original frame, locked-off static camera, fixed viewpoint and focal length throughout, plain light, sprite
```

这些是“保持原图取景、固定机位”的正向描述。[H3 提示指南](https://docs.comfy.org/tutorials/video/minimax/minimax-h3-prompt-guide)建议使用正向描述，避免在 BasicGuider 工作流里堆叠否定词。画布比例也应匹配参考图；自动适配比例的设置见下文 `match_reference_aspect`。

已有方案不会自动重写。增加或移除参考图后，可以手动修改旧提示词，或删除旧方案后重新规划；半身参考图的旧提示词应移除 `full body, full scene`。手动编辑的提示词始终按原文生成。

生成后展开卡片里的“从生成视频重新选帧”，拖动视频进度条，点击“使用 … 秒的画面”。这一步只读取已经生成的视频，不会重新调用模型。每次截帧都有独立结果，失败会保留上一张预览。勾选需要的立绘后添加到现有立绘集，提示词配对的标签会一起保存。

立绘标签统一以 2–3 个简短中文词语描述情绪、表情和动作，例如“开心，微笑，挥手”或“害羞，低头”。已有立绘的“智能标注”使用当前 Vision Adapter，只补充空白标签；MP4 会取中间帧送入视觉服务。模型输出不合格式时重试一次，仍不合格则保留空白并报告失败。

Vision Adapter 默认跟随 LLM 的配置与标注修复单独提交在 [PR #397](https://github.com/RachelForster/Shinsekai/pull/397)。

## 工作流与依赖细节

随附两个 API 格式工作流使用 480 × 832 竖向画布、107 帧、24 fps、8 步 Turbo LoRA，输出无声 MP4。需要本地已有对应 H3 主模型、Qwen 文本编码器、视频 VAE 和 Turbo LoRA；若文件名不同，请调整工作流中的模型名称。

H3 原生节点会直接将首帧拉伸到画布尺寸。适配器默认让 H3 画布匹配参考图比例，宽高按 32 像素对齐，总像素数和长边都不超过原工作流预算；再对参考图等比缩放，仅在剩余空隙补白。透明区域也会合成到白底，避免黑色边缘。这样保持人物比例，并减少因大面积补边造成的重新取景。例如 3:4 参考图在原 480×832 预算内使用 512×672 画布。

如果必须固定输出尺寸，可在扩展配置关闭 `match_reference_aspect`，此时只做等比缩放和补边。工作流同时连接其他首帧／尾帧时也会保留原画布，避免影响其他参考图。自定义工作流若用其他图像处理节点间接连接参考图，需自行保证最终画布比例；同一张图直连多个 H3 节点时，这些画布必须使用一致的整数尺寸。

默认开启“自动抠图”：生成的静态图、H3 自动提取的中间帧、重新选取的视频帧都会通过现有 `rembg` / `isnet-anime` 模型移除背景，输出保持原尺寸的透明 PNG。此步骤在本机 CPU 上执行，复用模型会话，不额外占用 H3 的 GPU 显存。关闭选项只影响后续生成或选帧；未抠图的结果仍可单独点击“移除背景”。预览使用棋盘格显示透明区域。

原始图片和视频保留在生成缓存内，不修改视频本身。抠图失败时保留原图并显示错误，点击“重新抠图”即可单独重试，不会再次运行 H3。确认满意后，再多选添加到角色立绘集，保存的是当前预览的 PNG 和标签。

首次使用抠图时会下载 `isnet-anime` 模型到 rembg 缓存目录；离线环境需预先下载模型。运行依赖 `rembg[cpu]` 包含 CPU 推理引擎，已有环境可以执行 `python -m pip install -r requirements-runtime-core.txt` 更新。之前已经被拉伸的视频无法仅靠换帧恢复人物比例，需要重新生成。

视频解码使用新增运行依赖 `av`（PyAV，提供 FFmpeg 解码能力），按时间定位并逐帧解码，不将整段视频读入系统内存。执行 `python -m pip install -r requirements-runtime-core.txt` 可安装。普通 SaveImage 工作流保持原有用法；SaveVideo 的 `images`、`videos` 或 `gifs` 历史输出均可识别，下载的源视频保存在立绘生成缓存中。

## 遇到问题时先检查哪一层

| 现象 | 检查方式 |
| --- | --- |
| ComfyUI 自己也不能生成、提示缺节点或模型 | 先按官方模板检查 ComfyUI 版本、模型目录和文件名；新世界不会补装这些依赖。 |
| 服务连接失败 | 确认 ComfyUI 仍在运行，API 地址和端口与浏览器访问的一致；连接已有服务不必填写启动目录。 |
| `Unsupported T2I adapter` | 适配器选择 `comfyui`，H3 模型名称写在工作流里。 |
| 提示词节点或输出节点不存在 | 附带工作流使用提示词 `131`、输出 `92`、参考图 `114`；自定义工作流按实际 ID 配置。 |
| 模型选项无效、找不到工作流文件 | 检查当前电脑的 JSON 绝对路径，以及 JSON 内模型名称是否与 ComfyUI 列出的文件一致。 |
| 能生成视频，但人物变窄 | 开启 `match_reference_aspect`；确认参考图未被其他节点再次拉伸。旧视频需要重新生成才能修正。 |
| 生成超时或显存不足 | 查看 ComfyUI 控制台，先单张测试；按模板降低分辨率或时长。首次加载较慢时增加 `generation_timeout`，勿连续重复提交。 |
| 立绘已有预览，但自动抠图失败 | 保留原图，检查 rembg 依赖及首次模型下载；用“重新抠图”重试，无需再次生成视频。 |

已经正常连接的其他 T2I 服务可以直接使用立绘生成。只有返回视频的工作流才提供选帧功能；普通图像工作流直接返回静态立绘。
